# rebalance-backend

API приложения для учёта личного бюджета: распределение дохода по категориям, автоклассификация транзакций, контроль лимитов и цели-накопления.

## Стек

Java 25, Spring Boot 4, PostgreSQL 18, Maven.

## Начало работы

Для запуска необходимы:

- JDK 25
- Docker с Docker Compose

Maven ставить не нужно, в репозитории есть Maven Wrapper (`./mvnw`).

В терминале:

```bash
docker compose up -d
./mvnw spring-boot:run
```

Проверка: http://localhost:8080/actuator/health

Параметры подключения к базе задаются переменными окружения `DB_URL`, `DB_USER`, `DB_PASSWORD`. По умолчанию используется база из `compose.yaml`.

## Команды

| Команда | Что делает |
|---|---|
| `./mvnw verify` | Сборка, линтер, проверка форматирования, тесты, отчёт о покрытии |
| `./mvnw spotless:apply` | Форматирует код |
| `./mvnw test` | Только тесты |

Для тестов нужен запущенный Docker: Testcontainers поднимает PostgreSQL сам.

Отчёт о покрытии: `target/site/jacoco/index.html`.

## Назначение директорий
| Папка | Слой | Что там лежит |
|---|---|---|
| `controller` | Слой представления (API) | Обработчики HTTP-запросов: принимают запросы от клиента, вызывают методы сервисов и возвращают ответы |
| `dto/request` | Слой представления (API) | Объекты, которые клиент отправляет в API |
| `dto/response` | Слой представления (API) | Объекты, которые API возвращает клиенту |
| `entity` | Слой данных | Сущности, представляющие данные приложения и соответствующие таблицам БД |
| `repository` | Слой доступа к данным | Интерфейсы для получения, сохранения, изменения и удаления данных в БД |
| `service` | Бизнес логика | Бизнес-правила и операции приложения: расчеты, проверки, обработка данных и взаимодействие с репозиториями |
